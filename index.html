Overview

CS 117 is a project-based introduction to computer vision: how machines acquire, process, and interpret images and video. We start from image formation, filtering, and local features, then build to the deep learning methods behind modern vision systems, including convolutional networks, vision transformers, and vision-language models.

Three problem sets build the skills step by step, and the quarter ends with a team final project that asks and answers your own question using open-source vision models.
